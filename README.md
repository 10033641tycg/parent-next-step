# parent-next-step
先接住，再處理

孩子的性影像被散布、被拿來威脅時，給家長看的行動指引。

開啟網址：https://10033641tycg.github.io/parent-next-step/

這個工具在做什麼

家長遇到這類事件時，常常不知道先做什麼，也容易在慌亂中做出讓情況更糟的決定，例如責罵孩子、替孩子付錢、把影像轉給別人「求證」。這個工具用幾個簡單的問題確認狀況，再依情況列出現在可以做的事、要避免的事，以及可以聯繫的單位。

首頁分成兩個入口。

「正在發生，需要現在處理」適合剛發現事件的家長。先確認孩子有沒有立即危險，再依五種情況提供行動清單：

孩子的性影像已經被散布
有人拿影像威脅孩子（性勒索）
孩子傳了影像給別人，目前還沒看到散布
孩子手機裡有別人的性影像，或孩子轉傳過
還不確定，只是聽說，孩子不肯說

「已經處理過了，接下來呢？」適合已經報案、通報，正在等待後續的家長，包含五個單元：

事後怎麼跟孩子重新談這件事
跟男孩談性與網路安全（針對詐財型性勒索）
復原期要留意的訊號
接下來的調查與司法流程
對方又來聯繫，或有人說能付費刪影像

每個頁面都可以列印或存成 PDF。

使用方式

用手機掃描 QR code 或直接開啟網址即可，不需要安裝任何程式。也可以下載 index.html，在電腦上用瀏覽器直接開啟，離線也能使用（撥號與外部連結需要網路）。

適用對象為未滿 18 歲兒少的家長或主要照顧者。

隱私
不收集、不儲存、不傳送任何資料，關掉頁面後所有勾選紀錄都會清除
沒有使用任何追蹤或分析工具
右上角的「快速離開」或鍵盤 Esc 鍵，可以立即跳離到 Google 首頁
網址刻意使用中性名稱，避免家中其他人從瀏覽紀錄看出內容
